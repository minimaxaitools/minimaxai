Words match assets by file name and keywords, e.g. volcano.jpg appears for "volcano". Tag explicitly with [heart](img), [plant](svg) or [rocket](img:🚀). For offline folders put files in kinetic/assets/ and run node build-wrappers.js.

Countries, Indian states and 1,600+ cities (English and Hindi names).

Map data: amCharts 5 geodata (Survey of India compliant boundary), GeoNames cities (CC BY 4.0). Compatible with any amCharts India JSON, district maps, or TopoJSON. Visual syntax: {"type":"map","focus":"IN","places":["Delhi","Mumbai"],"routes":[["Delhi","Mumbai"]]}

Browser voice is free but preview-only. ElevenLabs gives word-perfect timing and exports with the video.

Per sentence you can add "say" (pronunciation), "voiceId" (a second narrator) or "audio" (your own recording). Clips are cached, so re-rendering never pays twice.

—

A pack is a small JSON file with new presets (for example written by another AI from AI-PRESET-PRD.md). It merges over presets.motion.json, is checked for mistakes, and is remembered in this browser. For a permanent pack put it in kinetic/presets/ and run node build-wrappers.js.

Try previews a preset on a test line. Copy puts the reference you paste into content on the clipboard.

Rendering is frame-by-frame from the timeline, so every frame is exact regardless of machine speed.

MP4 (WebCodecs) is frame-exact for Chrome, Edge, and modern Safari. Universal MediaRecorder (MP4/WebM) and PNG sequence work across all iPad Safari, Android, and desktop browsers.

Missing presets, unknown tags and unmatched annotation targets never stop playback — the engine substitutes a default and lists it here.
